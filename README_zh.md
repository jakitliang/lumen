![lumen](etc/lumen.png)

> 照你来时路

## 简介

**流明（Lumen）** 是一个经现代化改良的 **路（Lua）**，基于并完全兼容 Lua 5.1。

面向热爱 Lua 的开发者，Lumen 提供了一个更现代、更可维护、并适配当代系统环境的全新实现。

## 特性

- **完全兼容**：与 Lua 5.1 脚本和 C 库完全兼容。
- **性能优化**：多项底层优化，提升运行效率，适合高性能应用场景。
- **易用性**：保留 Lua 5.1 简洁、易学、易集成的特性。
- **可扩展性**：提供更丰富的 API，便于开发者扩展和定制。
- **轻量级**：核心小巧高效，保持 Lua 一贯的轻量特性。
- **现代化**：更新底层架构，面向现代系统环境与开发需求。
